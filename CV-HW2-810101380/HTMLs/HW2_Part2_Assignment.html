2‑1. Denoising with Different Kernels¶

Why do blurring filters remove noise?
Blurring (low‑pass filtering) averages neighbouring pixel values. Random noise (like salt‑and‑pepper) has high spatial frequency; averaging reduces its amplitude. Gaussian blur uses a weighted average (normal distribution), while median filter replaces a pixel with the median of its neighbours – excellent for salt‑and‑pepper outliers.

We use:

  • Gaussian blur (kernel size 5×5) – a convolutional low‑pass filter.
  • Median filter (kernel size 3×3) – a non‑convolutional low‑pass filter.

These kernels differ from Part 1 (where we only used median 3×3). The assignment asks for a different kernel so here Gaussian 5×5 is new.

import os
import cv2
import numpy as np
import matplotlib.pyplot as plt

NOISY_DIR = "Noisy_Captcha"
GAUSSIAN_DIR = "DENOISED_GAUSSIAN"
MEDIAN_DIR = "DENOISED_MEDIAN"
SHARPENED_DIR = "Sharpened_Captcha"
BINARY_DIR = "Binary_Cleaned_Captcha"
MEAN_DIR = "DENOISED_MEAN"

for d in [GAUSSIAN_DIR, MEDIAN_DIR, SHARPENED_DIR, BINARY_DIR, MEAN_DIR]:
    os.makedirs(d, exist_ok=True)

noisy_files = [f for f in os.listdir(NOISY_DIR) if f.endswith('.png')]
if not noisy_files:
    raise FileNotFoundError("No noisy images. Run Part 1 first.")

print("Applying GaussianBlur (5×5), MedianBlur (3×3) and Mean filter (3×3)")
for fname in noisy_files:
    img = cv2.imread(os.path.join(NOISY_DIR, fname))
    gauss = cv2.GaussianBlur(img, (5, 5), 0)
    cv2.imwrite(os.path.join(GAUSSIAN_DIR, f"gauss_{fname}"), gauss)
    median = cv2.medianBlur(img, 3)
    cv2.imwrite(os.path.join(MEDIAN_DIR, f"median_{fname}"), median)
    mean = cv2.blur(img, (3, 3))   # 3x3 averaging kernel
    cv2.imwrite(os.path.join(MEAN_DIR, f"mean_{fname}"), mean)

print("Denoising complete.")

2‑2. Sharpening and De‑blurring¶

Sharpening enhances edges by emphasising high‑frequency components. A common kernel is:

[ \begin{bmatrix} 0 & -1 & 0 \\ -1 & 5 & -1 \\ 0 & -1 & 0 \end{bmatrix} ]

This kernel subtracts a smoothed version from the original, effectively adding the Laplacian.

Deblurring is a more advanced technique (e.g., Wiener filter, Richardson‑Lucy) that attempts to reverse a known blur kernel. Here we use simple sharpening to improve text clarity after denoising.

We apply sharpening to the median‑filtered images (because median preserves edges better than Gaussian).

In [27]:
sharpen_kernel = np.array([[0,-1,0], [-1,5,-1], [0,-1,0]], dtype=np.float32)
print("Sharpening kernel:\n", sharpen_kernel)

for fname in noisy_files:

    cv2.imwrite(os.path.join(SHARPENED_DIR, f"sharpened_{fname}"), sharpened)
print("Sharpening complete.")

2‑3. Binary Thresholding and Cleaning¶

Binary thresholding converts grayscale to black‑and‑white. A fixed threshold value (e.g., 160) determines the cut‑off:

  • Pixels above threshold become white (background), below become black (text).

Why is threshold not constant?
The optimal threshold depends on lighting, contrast, and noise. For our synthetic images, a fixed value works but may fail for real data. Adaptive thresholding (e.g., Otsu) would be more robust.

Small component removal uses connected components analysis: we remove blobs smaller than AREA_MIN (here 80 pixels) – these are likely residual noise. Then we apply morphological opening to separate touching components. Finally, we invert so that text is black on white background (standard for OCR).

In [29]:
THR = 160
AREA_MIN = 80

print(f"Threshold = {THR}, Minimum component area = {AREA_MIN}")

for fname in noisy_files:
    gray = cv2.imread(os.path.join(NOISY_DIR, fname), cv2.IMREAD_GRAYSCALE)
    _, binary = cv2.threshold(gray, THR, 255, cv2.THRESH_BINARY_INV)  # text white, background black
    # Connected components
    num_labels, labels, stats, _ = cv2.connectedComponentsWithStats(binary, connectivity=8)
    cleaned = np.zeros_like(binary)
    for i in range(1, num_labels):
        if stats[i, cv2.CC_STAT_AREA] >= AREA_MIN:
            cleaned[labels == i] = 255
    # Morphological opening to separate close components
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3,3))
    cleaned = cv2.morphologyEx(cleaned, cv2.MORPH_OPEN, kernel)
    # Invert to black text on white background
    final = cv2.bitwise_not(cleaned)
    cv2.imwrite(os.path.join(BINARY_DIR, f"cleaned_{fname}"), final)
print("Binary cleaning complete.")

Summary of Part 2 (Answering Each Question)¶

1. Why do blurring filters remove noise? (Using a different kernel from Part 1)¶

  • Explanation: Blurring (low‑pass filtering) averages neighbouring pixel values. Random noise (like salt‑and‑pepper or Gaussian) has high spatial frequency; averaging reduces its amplitude. The more pixels we average, the more noise is suppressed – but too much blurring also removes fine details (edges, text strokes).
  • Different kernel from Part 1:
    • Part 1 used median filter (3×3) – non‑convolutional, robust to outliers.
    • Part 2 uses Gaussian blur (5×5) – convolutional, weighted average (normal distribution).
    • Reason for change: Gaussian blur is a classic low‑pass filter; applying two different kernels demonstrates understanding of both approaches.
  • Result: Gaussian blur removes some noise but also slightly blurs characters; median filter (from Part 1) preserves edges better. We keep both for comparison.

2. Research on De‑blurring and Sharpening – applied method and justification¶

  • Sharpening enhances edges by emphasising high‑frequency components. It is a form of de‑blurring when the blur is mild.
  • Method chosen: Laplacian‑based sharpening kernel:
  • Why this method?
  • Simple, fast, and works well on text images after denoising.
  • It subtracts a smoothed version from the original, effectively adding the Laplacian to boost edges.
  • No need for complex deconvolution (e.g., Wiener filter) because our blur is not severe.
  • Result: Sharpening makes character edges crisper, improving subsequent segmentation and recognition.

3. Binary thresholding + removal of small connected components¶

  • Process:
  • Convert grayscale image to binary using a fixed threshold (160). Pixels below threshold become black (text), above become white (background).
  • Use connected components analysis to find all white blobs (text regions).
  • Remove components whose area is smaller than 80 pixels – these are considered noise.
  • Apply morphological opening to separate slightly touching characters.
  • What does the threshold mean?
  • A threshold value (e.g., 160) separates foreground (text) from background based on pixel intensity.
  • Is it constant? No, it is not universal. Optimal threshold depends on lighting, contrast, and noise level. For our synthetic images, 160 works well, but for real data, adaptive methods (Otsu, Sauvola) would be more robust.
  • Result: Clean binary images with black text on white background, ready for segmentation (Part 3). Small noise specks are removed.
